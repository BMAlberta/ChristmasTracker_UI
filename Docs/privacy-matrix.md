## Legend

| Symbol | Meaning |

| 200/201 | Success |
| BLIND | 200 with blinded/masked data (P1: recipient has credentials) |
| 403 | Forbidden (authenticated, lacking permission) |

| N/A | Not applicable (route not yet implemented) |

## Role Definitions

| Role | Description |
|------|-------------|
| selfListOwner | Owner of a self-list (userId === ownerId — blind) |
| selfListCoOwner | Co-owner of a self-list (blind per P1) |
| childListOwner | Owner of a child-list (not blind) |
| childListCoOwner | Co-owner of a child-list (not blind) |
| member | MEMBER-role member on the child-list |
| viewerMember | VIEWER-role member on the child-list |
| publicNonMember | Authenticated user, no membership on the PUBLIC list |
| privateNonMember | Authenticated user, no membership on the PRIVATE list |
| friendsOnlyNonMember | Authenticated user, no membership on a FRIENDS_ONLY list |
| removedMember | Previously REMOVED member |
| loggedInRecipient | Recipient with credentials — unreachable until children can log in (P9) |
| unauthenticated | No auth token |

## Notes

Outcomes the role grid cannot show:

- `PATCH /lists/{id}`: 422 CANNOT_EDIT_ARCHIVED_LIST (6402) for an owner or co-owner when the list is ARCHIVED, including un-archiving (L16).
- `POST /lists/{id}/members`: 409 MEMBERSHIP_ALREADY_EXISTS (5004) for an owner or co-owner when the target user already has an ACTIVE membership on the list.
- `DELETE /users/me/children/{id}`: 422 CANNOT_DELETE_RESOURCE (6501) when the child has a list that is not ARCHIVED (L17).
