## Legend

| Client Action | Meaning |
|---------------|---------|
| `re-login` | Drop all stored tokens; redirect to login screen |
| `refresh once and replay; if that fails, re-login` | Try one token refresh and replay the original request; redirect to login only if the refresh also fails |
| `force update` | Block the app; show update prompt with `details.minimumVersion` and `details.ipaUrl` |
| `treat as not found` | Resource does not exist or caller lacks permission (server never reveals which); show a generic "not found" state |
| `back off and retry` | Transient error; respect `Retry-After` header if present, otherwise use exponential back-off |
| `show message` | Display `error.message` to the user |
| `not an error: appears in warnings[] of a 200 confirmation_required response` | Not an error response; appears in the `warnings[]` array of a 200 OK response when a purchase would exceed budget (S6) |
