2. **5 nullable fields**: The original handoff stated these fields would "always be nil in I1-b." They are now optional Swift properties generated by the client. I1-b should map them to their actual values, not force nil.

4. **`doubleToDecimal` returns `Decimal?`**: I1-b callers must handle the optional. Nil indicates NaN/Infinity from the server.

5. **Stale-token detection**: `RefreshOn401Middleware` now skips refresh when the access token already rotated before the 401 response arrived. I1-b doesn't need to handle this; it's transparent.
