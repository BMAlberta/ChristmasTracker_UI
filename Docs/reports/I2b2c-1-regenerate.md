- No anyOf-null property was added or removed.
- After the regeneration, `swift build --package-path "LocalPackages/TrackerAPI"` ran the generator plugin and reported `Build complete!`.

Generated types after regeneration (source: reading `.build/plugins/outputs/trackerapi/TrackerAPI/destination/OpenAPIGenerator/GeneratedSources/`):
- `Components.Schemas.User.email: Swift.String` is non-optional (`Types+Components+Schemas.swift:258`).
- `data.expiresIn: Swift.Int` is required on login, register and refresh (`Types+Operations.swift:494, 836, 1189`).
- `Components.Responses.RateLimitError` has a body only and no headers (`Types+Components+Responses.swift:177-204`). `_Error.DetailsPayload` holds only `additionalProperties` (`Types+Components+Schemas.swift:342-360`). So neither a typed Retry-After nor a typed `details.retryAfter` exists, and the typed 429 arms use `retryAfter: 0`.

Repository mappings (`GeneratedClientAuthenticationRepository.swift`; no `default` in any switch):
- login: `.forbidden` maps to `accountDisabled` (lines 55-57). `.undocumented` now maps straight to `serverError` (66-67); the `status == 403` special case is removed. `.tooManyRequests` keeps `rateLimited(retryAfter: 0)`, with a comment added (60-63).
- refresh:
  - `.badRequest` maps to `validation(message:)` (159-161).
  - `.forbidden` maps to `accountDisabled` (162-164).
  - `.tooManyRequests` maps to `rateLimited(retryAfter: 0)` (167-170).
- logout:
  - `.forbidden` and `.notFound` map to `sessionExpired`, the session-ended error (197-199).
  - `.tooManyRequests` maps to `rateLimited(retryAfter: 0)` (200-203).
- register and checkAppVersion (`GeneratedClientAppVersionRepository.swift:33-65`): unchanged. Their documented codes did not change and the compiler required nothing.
- `mapUser`: uses `schema.email` directly (line 227). It keeps `throws` to avoid churn at the call sites, and the doc comment says so (222-223). This is a deviation from the story split; see Deviations.
- The 429 status on these POST operations is normally turned into `TrackerAPIError.rateLimited(retryAfter:)` by RateLimitMiddleware (`RateLimitMiddleware.swift:62-74`). That carries the Retry-After or `details.retryAfter` value, which reaches `AuthenticationError.rateLimited` through `classifyClientError`. The typed arms are the fallback for when that middleware is absent.
